# Sanket Sharma — ApexPlanet Internship Task 3

A responsive personal portfolio and interactive frontend playground built with **HTML5, CSS3, and vanilla JavaScript**.

## Task 3 requirements covered

1. **Responsive design using media queries**
   - Desktop, tablet, and mobile layouts.
   - Responsive navigation, grids, typography, and cards.
   - Reduced-motion accessibility support.

2. **Interactive JavaScript quiz and visual carousel**
   - Three-question multiple-choice quiz with instant feedback and score.
   - Three-slide carousel with previous/next controls and navigation dots.

3. **Fetch data from a public API**
   - Uses the JokeAPI programming/miscellaneous endpoint.
   - Displays fetched content dynamically.
   - Includes a fallback message if the network/API is unavailable.

## Run locally

1. Extract the ZIP.
2. Open the `Sanket_ApexPlanet_Task3` folder in VS Code.
3. Open `index.html` with **Live Server** (recommended), or open it directly in a browser.
4. Click **Fetch a joke** in the Interactive Lab section to test the API. Internet access is required for live API data.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive breakpoints
- `script.js` — navigation, quiz, API fetch, and carousel
